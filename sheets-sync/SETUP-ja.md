# セットアップ手順（LAUのGoogleアカウントで実施・所要10分程度）

ブラウザでの操作はこの1回だけです。以降の修正・テスト・運用は当方で回せます。

## 1. マスターのスプレッドシートを作る

[sheets.new](https://sheets.new) で新規作成し、名前を **「いちご在庫マスター」** にする。
中のシートは作らなくて構いません（スクリプトが作ります）。

## 2. スクリプトを貼る

同じファイルで **拡張機能 → Apps Script**。

1. 既定の `コード.gs` の中身を全部消し、`Code.gs` の内容を貼る
2. 左の「ファイル」＋ → スクリプト → 名前を `Setup` にして、`Setup.gs` の内容を貼る
3. 保存（⌘S）

## 3. 認証情報を登録する

Apps Script の左下 **⚙ プロジェクトの設定 → スクリプト プロパティ → プロパティを追加**。
4つ登録します。値は `~/.ichigo-shopify.env` にあるものです（当方から安全な経路で渡します。
**チャットに貼らないでください**）。

| プロパティ | 値 |
|---|---|
| `SHOPIFY_STORE` | `＊＊＊＊.myshopify.com`（`.myshopify.com` まで含める） |
| `SHOPIFY_CLIENTID` | カスタムアプリの Client ID |
| `SHOPIFY_SECRET` | カスタムアプリの Client secret |
| `ADMIN_EMAIL` | エラー通知の宛先メールアドレス |

## 4. 初回セットアップを実行

エディタ上部の関数プルダウンで **`setupWorkspace`** を選び ▶ 実行。

- 初回は Google の権限確認が出ます → 「詳細」→「（安全ではないページ）に移動」→ 許可
  （自作スクリプトなので未確認アプリ扱いになります。正常です）
- 実行が終わったら **「実行ログ」** に農家ファイルのURLが出ます

これで以下が自動生成されます：
- マスターに `Products` / `Log` / `Config` シート
- Shopifyの**販売元（vendor）ごとに**農家用スプレッドシートを1つずつ
  （`入荷入力` と `商品一覧`、E/F列と商品一覧は保護済み）

> ⚠️ 現在 vendor は `Berry Farm (Tanaka)` / `Farm B` / **`Ichigo`** の3つです。
> `Ichigo` は自社扱いのClub商品なので、農家ファイルは実質不要です。作られても害はありません
> （`Config` からその行を消せば対象外になります）。実データ確定時に整理しましょう。

## 5. 農家に共有する

`printFarmerFileUrls()` を実行するとURL一覧が出ます。
各ファイルを **その農家だけ**に「編集者」で共有してください。
**共有は自動化していません** — 誰に何を見せるかは人が決めるべきなので、意図的に手動です。

## 6. 定期実行をON

関数プルダウンで **`installTrigger`** を選び ▶ 実行。10分ごとに `runSync` が回ります。
