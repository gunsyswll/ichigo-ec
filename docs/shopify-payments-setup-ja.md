# Shopify ペイメント 登録手順書

Ichigo オンラインストア（`0ydzis-vt.myshopify.com`）

作成日：2026-07-20 ／ 対象：**登記済み法人**としてご登録される場合

---

## この手順書について

実際の管理画面を開いて、表示される項目を一つずつ確認しながら作成しています。
ステップ 1〜2 は実画面で確認済み、**ステップ 3〜6 は未確認**です（先へ進むには実際の
法人情報の入力が必要なため、確認を止めています）。該当箇所にその旨を明記しています。

---

## 事前にご用意いただくもの

登録を始める前に手元に揃えておくと、中断せずに完了できます。

### 必ず必要（ステップ 2 で入力）

- [ ] **登記上の法人名（漢字）** — 屋号ではなく、登記簿どおりの正式名称
- [ ] **登記上の法人名（カナ）**
- [ ] **登記上の法人名（ローマ字）**
- [ ] **法人番号（13桁）** — 国税庁の法人番号公表サイトで確認できます
- [ ] **登記上の本店所在地** — 郵便番号／都道府県／市区町村／町名／丁目／番地・号／建物名
- [ ] **電話番号**

### ステップ 3 以降で必要になる見込み（※未確認）

Shopify ペイメントは金融サービスのため、本人確認（KYC）が求められます。
一般的に以下が必要です。**実画面での確認は行っていません**ので、目安としてご覧ください。

- [ ] **代表者の情報** — 氏名（漢字・カナ・ローマ字）／生年月日／住所
- [ ] **代表者の本人確認書類** — 運転免許証、パスポート、マイナンバーカード等
- [ ] **実質的支配者の情報** — 議決権の一定割合以上を保有する方がいる場合
- [ ] **入金先の銀行口座** — 金融機関名／支店名／口座種別／口座番号／口座名義（カナ）
      ※ **法人口座**をご用意ください（法人登録の場合、個人口座は通常使用できません）
- [ ] **取扱商品の内容** — 事業内容の説明を求められます
- [ ] **明細書表記（customer billing statement）** — お客様のカード明細に表示される名称。
      「ICHIGO」など、お客様が見て分かる表記を推奨します

## 手順

### 【スクショ①】ステップ 0：決済設定を開く

1. Shopify 管理画面にログイン
2. 左サイドバー最下部の **「設定」** をクリック
3. 設定メニューから **「決済」** を選択
4. 画面上部の **「Shopify ペイメント」** の欄にある **「設定を完了」** ボタンをクリック

---

### 【スクショ②】ステップ 1/6：事業形態

3つの選択肢が表示されます。

| 選択肢 | 説明 |
|---|---|
| 個人 | 法人登録はしておらず、個人名義でストアを運営しています |
| **登記済み法人** | このストアを所有するビジネスがあり、日本政府に登記されています |
| 非営利団体 | このストアを所有する非営利団体があり、日本政府に登記されています |

1. **「登記済み法人」** を選択
2. 直下に **「事業形態を選択」** のドロップダウンが表示されます
3. **「会社」** を選択（※現在この選択肢のみ表示されます）
4. **「次へ」** をクリック

---

### 【スクショ③】ステップ 2/6：ビジネスの詳細

登記簿の記載どおりに入力してください。**屋号やブランド名ではありません。**

#### 法人情報

| 項目 | 必須 | 補足 |
|---|:---:|---|
| 登記上の法人名（漢字） | ● | 会社の正式な登記名 |

| 法人番号 | ● | **13桁** |
| 電話番号 | | 国番号 +81（日本）が既定 |

#### ビジネスの住所

「法的に登記されているビジネスの住所を入力してください」と案内されます。

| 項目 | 必須 | 補足 |
|---|:---:|---|

| 市区町村 | | |
| 町名 | | |
| 丁目 | | 例：６ |

### ステップ 3/6 〜 6/6（※未確認）

本手順書では、実際の法人情報を入力せずに確認できる範囲がステップ 2 までのため、
**ステップ 3 以降の画面は未確認**です。

進行状況は画面上部に「ステップ ○/6」と表示されますので、残り4ステップとなります。
「事前にご用意いただくもの」に挙げた情報（代表者情報・本人確認書類・銀行口座・
明細書表記）を順に求められる想定です。

各ステップは **「戻る」** で前に戻れます。また、途中で画面を閉じても、決済設定画面から
「設定を完了」で再開できます（入力途中の内容は保持される場合があります）。

## 登録後について

- Shopify による**審査**があります。審査中も一時的に決済を受け付けられる場合がありますが、
  **入金は審査完了後**となります
- 追加の書類提出を求められることがあります。管理画面の通知をご確認ください
- 有効化されると、決済設定画面の「Shopify ペイメント」欄が「設定を完了」から
  有効状態の表示に変わります

---

## ご注意

- **法人口座をご用意ください。** 法人として登録する場合、個人名義の口座は通常受け付けられません
- **登記情報と完全に一致させてください。** 法人名・住所が登記簿と異なると審査で差し戻されます
- **明細書表記**はお客様のカード明細に表示されます。ストア名と大きく異なると
  「身に覚えのない請求」としてチャージバック（不正利用申告）の原因になります

## 弊社側の対応事項

Shopify ペイメントが有効化されましたら、弊社にてサイト側を更新します。

- サイト上の決済手段の表示を、実際に利用可能な手段に合わせて更新
  （現在 GCash・Maya・VISA・Mastercard を表示していますが、実際に有効な手段へ差し替えます）
- テスト決済ゲートウェイの無効化
- 実際の決済フローの動作確認
