いちご在庫 入力マニュアル

農家さま用 ／ 2026年8月版
  1. 入荷したら 4つ書くだけ（日付・SKU・入荷数・メモ）
  2. 間違えたら 消さずに「マイナスの行」を足す
  3. グレーの列と カギ付きのタブは 触らない

ボタンを押す必要はありません。書いたら閉じて大丈夫です。
最大10分で自動的にお店の在庫に反映されます。

1. 画面の見かた

ファイルの下に4つのタブがあります。書くのは「入荷入力」だけです。

タブなにが見えるか
入荷入力入荷したものを書く場所（ここだけ書きます）
販売履歴何がいくつ売れたか（自動）
在庫台帳入荷と販売をまとめた一覧（自動）
商品一覧自分の商品と今の在庫（自動）

2. 入荷を書く

※ 画面のサンプル行は動作確認用です。実際のメモには「朝収穫」などを書いてください。

  1. 「入荷入力」タブを開く
  2. いちばん下の空いている行に、日付・SKU・入荷数・メモを書く
  3. Enterを押す。これで終わりです。ファイルを閉じて大丈夫です

書きかたの例

日付SKU入荷数メモ
2026/8/12ICH-00520朝収穫

しばらくすると「処理状態」に OK … と入ります。これがお店の在庫に反映された合図です。
「商品一覧」の現在庫も、その分だけ増えます。

いちばん大事なこと
ここに書くのは「今日いくつ入れたか」です。「今いくつあるか」ではありません。
今の在庫は「商品一覧」に自動で出ますので、書く必要はありません。

3. SKU（商品の番号）の調べかた

「商品一覧」タブを開くと、自分の商品と今の在庫が出ています。ここからSKUをコピーしてください。

4. 間違えたときの直しかた

書いた行は消さないでください。かわりに、マイナスの行を新しく足します。

日付SKU入荷数メモ
2026/8/12ICH-00520朝収穫 ← そのままにする
2026/8/12ICH-005-5傷み5パック廃棄 ← 新しく足す

多く書きすぎた・傷んで捨てた・数え間違えた — すべてこの方法で直せます。
伝票を消さずに、逆の伝票を1枚足すイメージです。

5. やってはいけないこと

  • 「処理状態」「処理日時」の列を書き換える（自動で入ります）
  • OK と入った行を書き換える・消す（直すときはマイナスの行を足す）
  • 在庫の数そのものを書き換えようとする（売れた分が消えてしまいます）
  • カギのマークが付いたタブを編集する（そもそも編集できません）

6. こんな表示が出たら

処理状態の表示意味とすること
OK gid://…反映ずみ。何もしなくて大丈夫です。
ERR SKU未解決(0件)SKUが違います。「商品一覧」から正しいSKUをコピーし直して、処理状態のセルを空にしてください（Deleteキー）。自動でやり直します。
ERR 入荷数が未入力または0数が空か0です。数を入れて、処理状態のセルを空にしてください。
ERR SKU重複(◯件)商品側の問題です。触らずにご連絡ください。
STUCK …絶対に消さないでください。送信の途中で止まった行です。消すと二重に登録される恐れがあります。そのままご連絡ください。
困ったとき・上の表で分からないときは、そのままにして担当者までご連絡ください。
無理に直そうとしなくて大丈夫です。書いた記録は残っていますので、あとから直せます。
